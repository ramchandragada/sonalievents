# Sonali Events

Website for [Sonali Events](https://www.sonali.events) — end-to-end event management in Pune (Nanded City, Sinhgad Road). Birthdays, naming ceremonies, engagements, marriages, housewarming, thread ceremonies, office parties, and celebration nights.

Proprietor: Mrs Sonali Rahul Upagnalawar.

Drop new photographs and videos into the `photos and videos` folder at the project root, then refresh the site. They appear on Home and Gallery.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Lenis
